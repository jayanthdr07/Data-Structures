# Data Structures and Algorithms (DSA)

This repository contains implementations and examples of **Data Structures and Algorithms (DSA)** concepts.  
It is intended for learning, practice, and revision of core DSA topics commonly asked in interviews and academic courses.

---

## 📚 Topics Covered

### 1. Arrays
- Basic array operations
- Traversal
- Insertion and deletion
- Searching techniques

### 2. Dynamic Memory Allocation (DMA)
- `malloc`, `calloc`, `realloc`, and `free`
- Memory management concepts
- Examples of dynamic arrays

### 3. Recursion
- Basics of recursion
- Recursive functions
- Examples like factorial, Fibonacci, etc.
- Understanding base and recursive cases

### 4. Stack
- Stack implementation
- Stack operations (push, pop, peek)
- Applications of stack

### 5. Queue
- Simple queue implementation
- Queue operations (enqueue, dequeue)
- Applications of queue

### 6. Circular Queue
- Circular queue implementation
- Advantages over linear queue
- Overflow and underflow handling

### 7. Linked List
- Singly Linked List
- Operations: insertion, deletion, traversal
- Searching elements in a linked list

### 8. Doubly Linked List (DLL)
- Doubly linked list structure
- Forward and backward traversal
- Insertion and deletion operations

### 9. Trees
- Tree basics
- Binary Tree concepts
- Tree traversal techniques (inorder, preorder, postorder)
